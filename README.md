# Trenches 1917: High Command

Western Front tactical browser game with WebSocket multiplayer.

## Play online (multiplayer)

**https://trenches.henrycui330.workers.dev**

> GitHub Pages cannot run WebSockets. Use the Cloudflare URL above.

## Local

```bash
npm install
npm start
```

Open **http://localhost:8765**

## Deploy updates

```bash
npx wrangler login   # once
npx wrangler deploy
```
